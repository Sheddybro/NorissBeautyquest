Install Noriss Beautyquest

Open this app on HTTPS or localhost, sign in, and wait for “Offline ready”.

  1. Android / desktop Chrome or Edge: use “Install app” when available, or the browser’s Install / Add to home screen menu.
  2. iPhone / iPad: open in Safari, tap Share, then Add to Home Screen.
  3. Offline use: reopen the app on this same trusted device. Save records normally; reconnect and keep the app open to sync.

Offline login is not a new authentication session. It uses the last downloaded workspace on this device. Protect the device with a screen lock.
